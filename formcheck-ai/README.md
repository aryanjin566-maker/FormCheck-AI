# Performance OS v4.0 (FormCheck AI)

**Performance OS v4.0** is an elite musculoskeletal analysis and strategic training protocol application. It leverages advanced Computer Vision and Large Language Models to provide athletes with a digital "Command Center" for their fitness journey.

## Core Features

### 1. Diagnostic Scan (AI Video Analysis)
The centerpiece of the application. Users can upload videos of themselves performing various exercises. The AI:
- Identifies the exercise.
- Counts repetitions or measures duration.
- Evaluates technique against athletic standards.
- Provides a "Form Score" (0-100).
- Offers specific, actionable feedback and corrective tips.

### 2. Strategic Command (AI Performance Coach)
A sophisticated chat interface powered by Gemini. It acts as a virtual performance coach and nutritionist, capable of:
- Architecting 12-month transformation protocols.
- Generating precision diet guides with macro-nutrient breakdowns.
- Providing weekly schedules and objective goals.
- Adapting plans based on recent diagnostic results.

### 3. Elite Leaderboard
A competitive ecosystem that ranks users based on a weighted "Command Score":
- **Streak (60%):** Rewards consistency and daily discipline.
- **Reps/Volume (20%):** Measures total physical output.
- **Variety (10%):** Encourages multi-disciplinary training (Unique Exercises).

### 4. Tactical Check-In
A daily synchronization module to track athletic streaks and session logs, fostering habit formation.

### 5. Historical Records
A complete archive of all diagnostic scans, allowing athletes to track their form improvement and volume history over time.

## Tech Stack
- **Frontend:** React (Vite), Tailwind CSS, Framer Motion.
- **Backend/DB:** Firebase Firestore, Firebase Authentication.
- **AI Engine:** Google Gemini (Gemini 3.1 Pro & Gemini 3 Flash).
- **Icons:** Lucide React.
- **Styling:** Technical, monochromatic "OS" aesthetic with high-contrast accents.
